# خلاصه فارسی

با استفاده از صدای استریم RTSP یک دوربین معمولی سعی کردیم دو دستگاه را پیدا کنیم: فن طبقه‌ی پایین و پمپ استخر.
گزارش کامل (روش، ریاضیات، آمار و نمودارها) در [REPORT.md](REPORT.md) است.

| سؤال | نتیجه |
|---|---|
| پمپ استخر | **شنیده می‌شود.** تطابق با برنامه‌ی ۳–۶ و ۱۵–۱۸ برابر ۹۵٫۸٪ دقیقه‌ها. آزمون جایگشت p = 0٫۰۰۳ و آزمون مستقل بین دو بازه d' حدود ۱٫۶ تا ۱٫۸ |
| فن با الگوی «۲۰ دقیقه روشن / ۴۰ دقیقه خاموش در هر ساعت» | **در داده نیست.** |
| یک منبع تناوبی دیگر | **پیدا شد:** دوره‌ی تناوب **۸۰٫۹۲ ± ۰٫۰۴ دقیقه**، ۱۸٫۹ دقیقه روشن و حدود ۶۲ دقیقه خاموش (p = 0٫۰۰۳). شبیه یک تایمر دقیق است |
| آیا همان فن است؟ | **تأیید نشده.** طول روشن (حدود ۲۰ دقیقه) می‌خواند ولی دوره‌ی ۸۱ دقیقه‌ای نه. یک بار فن را دستی روشن/خاموش کنید و ببینید فاز چرخه عوض می‌شود یا نه |

داده فقط طیف دقیقه‌ای ۲۰ تا ۱۰۰۰ هرتز است: بدون صدا، بدون تاریخ، بدون آدرس شبکه یا رمز.
